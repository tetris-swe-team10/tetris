# 벌칙 아이템 설계 초안

### 1. 암전 `B`

**벌칙 블록 고정 후 3초 동안, 보드에 쌓인 블록을 숨긴다.**

- 현재 조작하는 블록, 보드 외곽선, NEXT, 점수는 표시한다.
- 숨겨진 블록도 충돌·줄 삭제 판정에는 그대로 사용한다.
- 고스트 블록이 있다면 암전 동안 숨긴다.
- 시간이 끝나면 현재 보드 상태를 정상적으로 표시한다.
- 여러 블록을 빠르게 놓더라도 최초 발동 후 3초에 종료한다.

NEXT 안내: `B 암전 · 고정 후 쌓인 블록 3초 숨김`

### 2. 조작 반전 `R`

**벌칙 블록 고정 후 5초 동안, 좌우 이동 명령을 반대로 적용한다.**

| 입력 의도 | 실제 동작 |
| --- | --- |
| 왼쪽 이동 | 오른쪽 이동 |
| 오른쪽 이동 | 왼쪽 이동 |
| 회전·소프트 드롭·하드 드롭 | 기존 동작 유지 |
- 방향키나 사용자 지정 키를 해석한 뒤, 이동 명령 단계에서 반전한다.
- 설정 화면과 메뉴의 키보드 조작은 반전하지 않는다.
- 시간이 끝나면 즉시 정상 방향으로 복구한다.

NEXT 안내: `R 조작 반전 · 고정 후 좌우 5초 반전`

### 3. 회전 잠금 `K`

**벌칙 블록 고정 후, 바로 다음에 내려오는 블록 1개의 회전을 막는다.**

- 효과를 받는 다음 블록은 기본 생성 방향으로 등장한다.
- 좌우 이동·소프트 드롭·하드 드롭은 정상 동작한다.
- 모든 회전 명령을 무시하며, 잠금 표시로 이유를 알려준다.
- 대상 블록이 고정되면 효과가 끝난다.
- 시간 제한 없이 대상 블록의 수명에 따라 유지한다.

NEXT 안내: `K 회전 잠금 · 고정 후 다음 블록 1개 회전 금지`
