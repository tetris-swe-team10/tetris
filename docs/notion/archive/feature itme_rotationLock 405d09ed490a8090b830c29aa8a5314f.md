### 회전 `K`

| 항목 | 변경된 설계 |
| --- | --- |
| **발동** | NEXT의 K 블록이 현재 조작 블록으로 등장하는 순간 |
| **표현** | 블록에 `K` 표시, `K 회전 잠금 · 현재 블록` 안내 |
| **시야** | 보드와 블록 모두 정상 표시 |
| **유지** | K 블록은 기본 생성 방향을 유지하며 모든 회전 명령을 무시 |
| **종료** | K 블록이 고정되는 즉시 종료. 다음 블록은 정상 회전 |
| **유지되는 조작** | 좌우 이동·소프트 드롭·하드 드롭·충돌·줄 삭제·점수는 정상 동작 |
