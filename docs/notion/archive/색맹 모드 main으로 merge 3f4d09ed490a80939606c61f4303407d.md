## 1. 배경

- 색맹 모드 브랜치를 main에 합치기 전에, 다른 팀원의 **점수·난이도 작업(d09eec9)** 이 main에 먼저 merge됨
- 이 작업으로 게임 구조가 크게 바뀌어서 색맹 브랜치를 그대로 PR로 올리면 충돌이 나고, 일부 기능이 깨지는 상황
- 그래서 PR 전에 **최신 main을 내 브랜치로 가져와서(merge) 맞추는 작업**을 진행함

## 2. main에서 바뀐 구조 (색맹 모드와 관련된 것)

| 항목 | 이전 | 변경 후 |
| --- | --- | --- |
| 화면이 데이터를 읽는 방식 | `GameView`가 `Board`를 직접 읽음 | `GameEngine`이 만든 읽기 전용 복사본(`GameSnapshot`)만 읽음 |
| 줄 삭제 | 꽉 차면 `clearLines()`로 즉시 삭제 | `findFullRows()` → 0.3초 흰색 연출(`CLEARING`) → `removeRows()`로 삭제 |
| 입력 처리 | `GameView`에서 엔진 직접 호출 | `GameController`가 담당 |

## 3. 문제점 분석

### ① Board: 줄을 지울 때 블록 종류가 따라 내려가지 않음

- `Board`에는 표가 두 개 있음
    - `cells`: 칸이 차 있는지 (0/1)
    - `cellTypes`: 어떤 블록인지 (색맹 모드에서 추가)
- 새 `removeRows()`는 `cells`만 내리고 `cellTypes`는 그대로 둠
→ 줄 삭제 후 **블록 위치는 맞는데 색이 틀리는** 버그 발생
- Git이 충돌로 알려 주지 않는 문제라서 직접 찾아서 고쳐야 했음

### ② snapshot: 쌓인 블록 종류가 화면에 전달되지 않음

- `GameSnapshot`에는 칸 정보(0/1)만 있고 블록 종류가 없음
- 현재 블록과 NEXT는 `PieceSnapshot.type()`이 있어서 괜찮음
- 고치지 않으면 쌓인 블록이 다시 한 가지 색으로 돌아감

### ③ Git 충돌

- `Board.java`, `GameView.java`: 같은 부분을 양쪽이 다르게 고쳐서 충돌
- `App.java`: 서로 다른 줄이라 자동으로 합쳐짐

## 5. 다른 팀원 코드 수정 내역

점수·난이도 문서 "팀원 연동 시 주의 4번"에 따른 수정 (담당 팀원 공유 완료)

- `Board.removeRows()`: `cellTypes`도 함께 이동 (2줄 추가)
- `GameSnapshot`: `cellTypes` 항목 추가 (빈칸 null 허용 방식으로 복사)
- `GameEngine.snapshot()`: `cellTypes` 채우기
- 다른 팀원의 테스트는 수정하지 않음
