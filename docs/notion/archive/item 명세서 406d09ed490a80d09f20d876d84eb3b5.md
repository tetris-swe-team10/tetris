# item 명세서

생성자: 박서현
우선순위: 높음
카테고리: 분석
상태: 시작 전

**공통 지급 규칙**

- 아이템 모드에서 **누적 10줄을 삭제할 때마다** 5종 중 선택 가능한 아이템을 균등 무작위로 지급한다.
- 이미 표시된 NEXT는 유지하고, **새로 보충되는 NEXT**에 아이템을 예고한다. 초과 삭제 줄 수는 보존한다.
- 암전(B)·회전 잠금(K)이 예약되거나 진행 중이면 두 벌칙을 추첨에서 제외하고 E/L/W 중 선택한다.
- 일반 모드에서는 아이템을 지급하지 않는다.

| 아이템 | 형태·표시 | 발동 및 효과 | 유지·종료 | 점수·줄 수 |
| --- | --- | --- | --- | --- |
| **암전 `B`** | 일반 블록의 무작위 점유 칸에 부착 | B 블록 고정 후 **다음 블록**에 적용. 보드를 어둡게 하고, 조작 블록을 따라 움직이는 **지름 약 4칸의 원형 영역**만 밝게 표시 | 시간 제한 없이 대상 블록이 착지할 때 종료. 현재 블록·NEXT·점수는 표시하고 고스트는 숨김. 충돌 판정은 유지 | 기존 점수·줄 삭제 규칙 유지 |
| **줄 삭제 `L`** | 일반 블록의 무작위 점유 칸에 부착 | 블록 고정 시 **L이 위치한 행 전체 삭제**. 행이 꽉 차지 않아도 작동 | 0.3초 강조 후 삭제하고 위 행을 내림. 완성 행과 겹치면 한 번만 처리 | 일반 줄 삭제와 동일하게 점수 지급. 누적 줄·가속·다음 아이템 지급에 포함 |
| **작은 폭탄 `E`** | 일반 블록의 무작위 점유 칸에 부착 | 블록 고정 시 **E 칸 중심 3×3**의 블록 제거 | 제거 대상이 0.3초 동안 두 번 깜빡인 뒤 삭제. 위 블록은 내려오지 않으며 연쇄 발동 없음 | 폭발로 제거한 칸은 무득점·줄 수 미포함. 폭발 후 남은 완성 행은 정상 채점 |
| **무게추 `W`** | 블록 자체가 아이템. 너비 4칸, `.WW.` / `WWWW` 형태 | 접촉 전에는 좌우 이동 가능. 최초 접촉 후 좌우 이동을 잠그고, 낙하 틱마다 내려가며 **겹치는 블록 제거** | 회전 불가. 바닥에 도달하면 사라짐. 파괴 중 아래 키·하드 드롭은 남은 파괴를 즉시 진행 | 접촉 전 낙하 점수는 정상 지급. 파괴한 칸은 무득점·줄 수 미포함 |
| **회전 잠금 `K`** | 일반 블록의 무작위 점유 칸에 부착 | **K가 붙은 블록 자체**가 기본 생성 방향으로 등장하며 모든 회전 명령을 무시 | K 블록이 고정되면 종료. 시간 제한 없음. 좌우 이동·소프트 드롭·하드 드롭은 정상 동작 | 기존 점수·줄 삭제 규칙 유지 |

**구현 구조**

| 구성요소 | 역할 |
| --- | --- |
| `GameItem` | 아이템별 문자·설명·효과와 발동 시점 정의 |
| `RandomItemAssigner` | 선택 가능한 아이템 추첨 및 무작위 칸 부착. 무게추는 전용 블록으로 교체 |
| `ItemAttachment` | 부착 위치를 관리하고 블록 이동·회전 시 일관성 유지 |
| `PenaltyController` | 암전·회전 잠금의 예약·활성·종료 및 중첩 방지 |
| `GameEngine` | 고정·연출·삭제·점수·다음 블록 생성 순서 처리 |
| `GameSnapshot` / `GameView` | 게임 상태를 받아 NEXT 안내·아이템 표시·효과 렌더링 |
