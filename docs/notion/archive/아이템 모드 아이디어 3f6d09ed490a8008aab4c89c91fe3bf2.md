# 아이템 모드 아이디어

생성자: 정혜원
카테고리: 아이디어
상태: 완료

### 1. 작은 폭탄 `E`

**아이템 블록이 고정되면, 아이템 칸을 중심으로 3×3 영역의 블록을 삭제한다.**

- 기본 블록 한 칸에 붙는 아이템이다.
- 보드 밖으로 나간 범위는 무시한다.
- 삭제된 공간 위의 블록은 자동으로 떨어뜨리지 않는다.
- 일반 줄 삭제처럼 빈 행을 압축하는 효과도 없다.
- 폭발 범위에 다른 아이템이 있어도 연쇄 발동하지 않는다.

**장점:** 행·열 전체 삭제보다 범위가 작아서, 막힌 부분을 겨냥해 놓는 재미가 있다. 기존 삭제 아이템과 역할을 구분하기도 쉽다.

NEXT 안내: `E 작은 폭탄 · 고정 후 주변 3×3 삭제`

### 2. 성장 주사 `S`

**회전할 수 없는 세로 일자형 아이템으로, 고정되면 바로 아래에 닿은 블록의 모양을 성장시킨다.**

- 성장 주사는 효과를 적용한 뒤 사라진다.
- 아래에 닿은 **블록 한 개**를 대상으로 한다. 같은 종류의 블록 전체가 커지는 것은 아니다.
- T 블록은 현재 방향을 기준으로 세 갈래 끝에 한 칸씩 추가한다.
- I 블록은 길이가 한 칸 늘어나 **4칸 → 5칸**이 된다.
- 성장할 위치가 벽이나 다른 블록으로 막혀 있으면, 추가하지 못한 칸 수만큼 대상 블록 위쪽으로 솟아난다.
- 성장으로 가로줄이 완성되면 일반 줄 삭제를 적용한다.

**장점:** 구멍을 채워 줄을 완성할 수도 있지만, 잘못 놓으면 위로 솟아 보드가 높아진다. 대상 블록의 모양과 주변 공간을 보고 사용하는 재미가 있다.

NEXT 안내: `S 성장 주사 · 아래 블록 성장, 막힌 만큼 위로 돌출`

### 3. 도박 상자 `?` — 행운의 청소

**획득한 상자를 원하는 시점에 사용하면, 확률에 따라 보드 아래쪽을 정리하거나 쓰레기 줄을 추가한다.**

- 상자는 최대 1개 보관한다.
- 전용 키로 사용하거나 버릴 수 있다.
- 다음 블록이 등장하기 직전에 효과를 적용한다.
- **성공 60%:** 보드 맨 아래 2행의 고정 블록을 제거하고, 위의 행을 내려 빈 공간을 채운다.
- **실패 40%:** 빈칸이 하나씩 있는 쓰레기 2행을 아래에 추가하고, 기존 보드를 위로 올린다.
- 위로 밀린 블록이 보드 밖으로 나가면 게임 오버가 된다.
- 성공으로 제거한 행은 일반 줄 완성과 구분해 점수·속도 증가에는 포함하지 않는다.
- 확률은 사용 전에 표시하고, 결과는 사용 후 공개한다.

안내: `? 도박 상자 · 사용 시 60% 아래 2줄 제거 / 40% 쓰레기 2줄 추가`
