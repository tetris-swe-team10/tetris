| 화면 | 구현할 것 |
| --- | --- |
| 시작 | 게임 시작 / 설정 / 스코어보드 / 게임 종료 메뉴. 방향키로 메뉴 이동, **Enter(리턴)** 키로 선택. 게임 종료 시 프로그램 종료. |
| 게임 | 10×20 보드, 블록 이동·회전·낙하, 점수·지운 줄·다음 블록 표시. 일시정지와 설정 화면 진입. |
| 설정 | 낙하 속도, 조작 키, 색맹 모드 등 변경. 들어오기 전 화면으로 돌아가기. |
| 스코어보드 | 최고 점수 등 게임 기록 표시. 시작 화면으로 돌아가기. |
| 결과 | 최종 점수와 기록 표시. 다시 시작 / 시작 화면 / 게임 종료 선택. |
