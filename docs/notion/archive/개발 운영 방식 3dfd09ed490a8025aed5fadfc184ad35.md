# 개발 운영 방식

생성자: 박서현
우선순위: 높음
상태: 진행 중

### 커밋 방식

| 종류 | 사용하는 상황 | 예시 |
| --- | --- | --- |
| `feat` | 새로운 기능을 추가할 때 | `feat: 시작 화면 키보드 메뉴 선택 추가` |
| `fix` | 잘못 동작하는 기능을 고칠 때 | `fix: 블록 회전 시 보드 밖으로 나가는 오류 수정` |
| `docs` | 문서만 변경할 때 | `docs: 화면별 구현 계획 추가` |
| `refactor` | 동작은 유지하면서 코드 구조를 정리할 때 | `refactor: 화면 전환 로직 분리` |
| `test` | 테스트를 추가하거나 수정할 때 | `test: 점수 계산 테스트 추가` |
| `chore` | 빌드 설정 등 기능 외 작업을 할 때 | `chore: 빌드 설정 정리` |

### 작업 단위

| 작업 단위 | 작업 브랜치 (예시) |
| --- | --- |
| 화면별 구현 계획 정리 | `docs/screen-plan` |
| 시작 화면과 키보드 메뉴 | `feature/start-menu` |
| 게임 화면과 블록 조작 | `feature/game-play` |
| 설정 화면 | `feature/settings` |
| 스코어보드 | `feature/scoreboard` |
| 결과 화면 | `feature/result-screen` |
