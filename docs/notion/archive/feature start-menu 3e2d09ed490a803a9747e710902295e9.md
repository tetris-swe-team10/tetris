## 코드 구조

| 구분 | 역할 |
| --- | --- |
| `MenuSelectionModel` | 현재 메뉴 위치와 순환 이동 상태 관리 |
| `MenuCommand` | 이전 이동, 다음 이동, 선택 명령 정의 |
| `MenuKeyBindings` | 키보드 키와 메뉴 명령 연결 |
| `StartMenuAction` | 시작 화면 메뉴 종류와 표시 순서 정의 |
| `StartScreen` | 화면 구성과 키보드·마우스 입력 처리 |
| `App` | 시작 화면, CSS, 종료 동작 조립 |

## 구현 기능

- 게임 시작, 설정, 스코어보드, 게임 종료 메뉴 표시
- 방향키 `↑` `↓`와 `W` `S`를 이용한 메뉴 이동
- `Enter` 키를 이용한 메뉴 선택
- 첫 메뉴와 마지막 메뉴 사이의 순환 이동
- 현재 선택된 메뉴를 하나의 선택 박스로 표시
- 마우스와 키보드를 함께 사용할 때 가장 최근 입력을 기준으로 선택 갱신
- 아직 구현되지 않은 메뉴는 비활성화
- 게임 종료 메뉴를 JavaFX 애플리케이션 종료 동작과 연결
- CSS를 이용한 시작 화면 디자인 적용
