# 테트리스 게임 조작법

생성자: 정혜원
상태: 완료

# 1. 키보드 조작

| 키 | 기능 |
| --- | --- |
| ← | 블록 왼쪽 이동 |
| → | 블록 오른쪽 이동 |
| ↓ | 블록 한 칸 아래로 이동 |
| ↑ | 블록 시계 방향 90° 회전 |
| Space | 하드 드롭: 블록을 바닥 또는 다른 블록 위까지 즉시 낙하 |
| ESC | 게임 일시정지 / 재개 |

## 2. 게임 진행

- 10×20 보드에서 7종 블록이 무작위로 생성됨.
- 블록이 일정 시간마다 자동으로 한 칸씩 낙하함.
- 블록이 바닥이나 다른 블록에 닿으면 현재 위치에 고정되고 다음 블록이 생성됨.
- 가로 한 줄이 모두 채워지면 해당 줄이 삭제됨.
- 지운 줄이 누적 5줄에 도달할 때마다 자동 낙하 속도가 증가함.
- 다음 블록을 생성할 공간이 없으면 게임 오버 처리됨.

## 3. 일시정지 및 설정

- ESC를 누르면 게임이 일시정지되고, 다시 누르면 재개됨.
- 일시정지 중에는 블록 이동·회전·낙하가 차단됨.
- 게임 화면의 설정 버튼은 설정 화면 이동을 위한 연결 지점으로 구현함.
- 실제 설정 화면은 담당자 코드와 통합 후 연결 예정.

## 4. 현재 구현 상태

- 완료: 보드·블록 표시, 키보드 조작, 자동 낙하, 하드 드롭, 일시정지·재개, 다음 블록 표시, 지운 줄 표시, 게임 오버 판정.
- 연동 예정: 점수 담당자의 점수 계산 로직, 설정 화면, 게임 오버 결과 화면.
- 확인 완료: Gradle 빌드 성공 및 게임 화면 실행·조작 확인.
