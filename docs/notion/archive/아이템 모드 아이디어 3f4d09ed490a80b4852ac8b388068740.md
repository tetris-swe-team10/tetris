# 아이템 모드 아이디어

생성자: 정수연
카테고리: 아이디어
상태: 완료

1. 세로 줄 삭제 (V)
- 기본 블럭 한 칸에 무작위로 붙는 아이템
- 블럭이 고정되면 V가 있던 열 전체를 위에서 아래까지 삭제
    - 기본 블럭 한 칸에 무작위로 붙는 아이템
- L(가로 줄 삭제)과 대칭되는 아이템이라 깊게 파인 세로 구멍 정리할 때 유용

1. 중력 (G)
- 블럭이 고정되면 보드 전체의 블럭들이 각 열마다 아래로 떨어져 빈 공간을 메움
- 그 결과 꽉 찬 줄이 생기면 한 번에 여러 줄 삭제 가능
- 무게추가 블럭을 없애는 거라면, 이건 블럭을 재배치해서 막힌 판을 살려주는 역할

1. 구멍 메우기 (F)
- 1칸짜리 블럭 자체가 아이템
- 블럭에 닿으면 멈추지 않고, 같은 열 아래쪽의 가장 깊은 빈칸으로 이동해서 구멍을 메움
- 위가 막혀서 못 채우던 구멍을 정확히 메울 수 있음
- 무게추가 지워서 정리하는 거라면, 이건 채워서 정리하는 반대 개념
