## 설정 화면 및 게임 설정 상태 관리

구현 브랜치: `feature/setting`

시작 메뉴에서 여는 전체 설정 화면과 게임 중 일시정지 설정 창이 같은 설정 상태를 공유하도록 구현했다.

## 화면 구성

- `SettingsScreen`: 시작 메뉴에서 진입하는 전체 화면 설정
- `PauseSettingsPane`: 게임 중 ESC를 눌렀을 때 표시되는 설정 창
- `SettingsPanel`: 두 화면에서 공통으로 사용하는 설정 UI
- 설정 항목은 세로로 스크롤할 수 있다.
- 스크롤바 UI는 숨기고 스크롤 기능만 제공한다.
- 시작 화면 버튼은 중앙에 배치한다.
- 점수 초기화 버튼은 오른쪽에 배치한다.

## 설정 상태

설정값은 `GameSettings`에서 통합 관리한다.

- 낙하 속도: `DropSpeed`
- 화면 모드: `DisplayMode`
- 색맹 모드
- 데모 모드

전체 설정 화면과 게임 중 설정 창이 같은 `GameSettings` 객체를 사용하므로 한쪽에서 변경한 설정이 다른 화면에도 반영된다.

## 낙하 속도

| 설정 | 화면 표시 | 배율 |
| --- | --- | --- |
| `SLOW` | 느리게 | 1.25 |
| `NORMAL` | 보통 | 1.0 |
| `FAST` | 빠르게 | 0.75 |

`DropSpeed.adjustInterval()`이 게임에서 계산된 자동 낙하 간격에 배율을 적용한다.

기본 간격이 1000ms인 경우:

- 느리게: 1250ms
- 보통: 1000ms
- 빠르게: 750ms

게임 시작 시 선택하는 난이도와 설정 화면의 낙하 속도는 별도로 관리한다.

- 난이도: 기본 낙하 간격과 게임 진행 규칙 결정
- 낙하 속도 설정: 계산된 간격에 사용자 배율 적용

## 화면 모드

다음 화면 모드를 선택할 수 있다.

- 전체 화면
- 창 모드
- 세로 모드

ComboBox에서 Enter 또는 Space로 선택을 적용한다. ESC나 Tab으로 목록을 닫으면 기존 설정을 유지한다.

실제 JavaFX `Stage` 변경은 설정 화면이 직접 처리하지 않고 App 계층에 콜백으로 전달한다.

## 색맹 모드와 설정 저장

`SettingsManager`가 색맹 모드 설정을 저장하고 불러온다.

- 저장 키: `colorBlindMode`
- 설정값이 없으면 기본값은 `false`
- 설정 파일을 읽지 못해도 기본값으로 실행
- 저장에 실패하면 로그를 남기고 애플리케이션 실행은 유지

색맹 블록 표시와 게임 화면 렌더링은 색맹 기능 브랜치에서 추가로 연결해야 한다.

데모 모드는 현재 설정 상태와 UI만 제공한다.

## 키보드 조작

`SettingsNavigation`이 공통 키보드 이동을 담당한다.

- 위/아래 또는 W/S: 설정 항목 이동
- 왼쪽/오른쪽 또는 A/D: 같은 항목의 선택지 이동
- Enter 또는 Space: 선택 및 버튼 실행
- ESC: 시작 화면으로 돌아가기 또는 게임 재개
- 포커스가 이동하면 해당 설정 항목이 보이도록 자동 스크롤

## 게임 중 설정 연동

게임 중 ESC를 누르거나 설정을 요청하면 다음 순서로 처리한다.

1. 게임을 일시정지한다.
2. 자동 낙하와 게임 입력을 중지한다.
3. `PauseSettingsPane`을 표시한다.
4. 설정 창을 닫으면 이전 일시정지 상태를 확인한다.
5. 재개할 수 있는 상태라면 게임을 다시 진행한다.

## 파일 구성

| 구분 | 파일 | 역할 |
| --- | --- | --- |
| Model | `GameSettings` | 공통 설정 상태 관리 |
| Model | `DropSpeed` | 낙하 속도 종류와 배율 관리 |
| Model | `DisplayMode` | 화면 모드 종류 관리 |
| Persistence | `SettingsManager` | 설정 저장 및 불러오기 |
| Shared View | `SettingsPanel` | 공통 설정 UI |
| Navigation | `SettingsNavigation` | 키보드 이동 처리 |
| Full Screen View | `SettingsScreen` | 시작 메뉴 설정 화면 |
| Pause View | `PauseSettingsPane` | 게임 중 설정 창 |
| Style | `settings.css` | 설정 화면 스타일 |

## 팀원 연동 시 주의사항

1. 난이도는 게임 시작 시 `GameConfig`로 확정하므로 설정 화면에 추가하지 않는다.
2. 키 변경 버튼은 UI와 콜백 연결 지점만 제공한다.
3. 키 변경 콜백이 연결되지 않았다면 버튼을 비활성화한다.
4. 점수 초기화는 설정 화면이 직접 기록을 삭제하지 않고 App에서 전달한 콜백을 실행한다.
5. 새로운 공통 설정 항목은 `SettingsPanel`에 추가한다.
6. 영구 저장이 필요한 설정은 `SettingsManager`에 저장 키, 기본값, 오류 처리를 함께 추가한다.

## 검증 및 실행

```
./gradlew test
./gradlew uiTest
./gradlew run
```

Gradle Wrapper 실행 권한이 없다면 다음과 같이 실행할 수 있다.

```
sh ./gradlew test
```

- `test`: 설정 상태와 입력 처리 등 일반 로직 테스트
- `uiTest`: JavaFX 화면과 사용자 입력 테스트
- `run`: 애플리케이션 실행

## 현재 구현 범위

- 전체 설정 화면
- 게임 중 일시정지 설정 창
- 공통 설정 상태 관리
- 낙하 속도 설정
- 화면 모드 선택
- 색맹 모드 저장
- 키보드 탐색
- 게임 일시정지 및 재개 연동
