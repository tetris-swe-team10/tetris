# 네이버 지도 개선 - 여러 장소의 방문 경로 계획

## 1. User Story

사용자는 하루에 식당, 카페, 전시관 등 여러 장소를 방문할 때 장소마다 길찾기를 따로 검색하고, 어떤 순서로 방문해야 이동 시간이 적은지 직접 비교해야 하는 점이 불편하다.

따라서 방문하고 싶은 장소를 여러 개 선택하면 각 장소 사이의 거리와 이동 시간을 계산하여 **효율적인 방문 순서와 전체 이동 경로를 한 번에 보여주었으면 한다.** 또한 방문 장소를 추가하거나 삭제하면 변경된 일정에 맞게 경로가 다시 계산되었으면 한다.

## 2. Scenario

### S1. 여러 장소의 방문 경로 생성

- **시작 상황:** 사용자가 방문하려는 장소를 여러 개 선택한 상태
- **행동:** ‘방문 경로 추천’을 선택
- **결과:** 장소 간 거리와 이동 시간을 계산하여 추천 방문 순서, 전체 이동 경로, 예상 이동 시간을 표시
- **예외 상황:** 이동할 수 없는 장소가 포함된 경우 해당 장소를 안내하고 가능한 장소를 기준으로 경로를 다시 계산

### S2. 방문 장소 변경

- **시작 상황:** 여러 장소에 대한 추천 경로가 생성된 상태
- **행동:** 사용자가 새로운 장소를 추가하거나 기존 장소를 삭제
- **결과:** 변경된 장소를 기준으로 방문 순서와 전체 경로를 다시 계산
- **예외 상황:** 장소 정보 조회에 실패하거나 영업이 종료된 장소가 있는 경우 사용자에게 안내

## 3. Task & Iteration Planning

- 프로젝트 세팅 및 기본 지도 화면 구현 `(T1, 6h)`
- 여러 방문 장소 선택 및 저장 기능 `(T2, 8h)`
- 선택한 장소의 위치 정보 조회 `(T3, 6h)`
- 장소 간 거리 및 이동 시간 계산 `(T4, 8h)`
- 방문 순서 추천 로직 및 단위 테스트 `(T5, 10h)`
- 추천 방문 경로 지도 표시 `(T6, 8h)`
- 전체 예상 이동 시간 및 거리 표시 `(T7, 6h)`
- 방문 장소 추가·삭제 기능 `(T8, 6h)`
- 장소 변경 시 경로 자동 재계산 `(T9, 8h)`
- 방문 순서 직접 변경 기능 `(T10, 6h)`
- 이동 불가·정보 조회 실패 등 예외 처리 `(T11, 6h)`
- 전체 시나리오 통합 테스트 `(T12, 8h)`

### Iteration 1 - 기본 방문 경로 추천

**목표:** 여러 장소를 선택하면 방문 순서와 전체 이동 경로를 확인할 수 있는 기본 기능 완성

포함 Task: **T1, T2, T3, T4, T5, T6, T7**

T3의 위치 정보가 있어야 T4에서 거리와 이동 시간을 계산할 수 있고, T4의 결과를 바탕으로 T5에서 방문 순서를 결정할 수 있다. 이후 T5 결과를 이용하여 T6에서 경로를 지도에 표시하고 T7에서 전체 이동 시간과 거리를 제공한다.

→ Iteration 1 종료 시 **여러 장소 선택 → 추천 방문 순서 계산 → 지도에서 전체 경로 확인**까지 시연 가능.

### Iteration 2 - 경로 변경 및 예외 처리

**목표:** 사용자의 일정 변경에 대응할 수 있도록 기존 경로 추천 기능 확장

포함 Task: **T8, T9, T10, T11, T12**

T8에서 장소 추가·삭제 기능을 구현한 뒤, Iteration 1에서 구현한 경로 계산 기능을 이용하여 T9의 자동 재계산 기능을 구현한다. 이후 사용자가 직접 방문 순서를 수정할 수 있는 T10과 예외 상황을 처리하는 T11을 추가하고, 마지막으로 T12에서 전체 Scenario를 통합 테스트한다.

→ Iteration 2 종료 시 **장소 변경에 따라 경로를 수정하고 예외 상황까지 처리할 수 있는 최종 기능** 완성.

## 4. Sprint 1 계획

**Sprint 기간:** 2주

**Sprint 목표:** 여러 방문 장소를 선택하면 효율적인 방문 순서와 이동 경로를 지도에서 확인할 수 있도록 구현

- **팀원 A:** T1 프로젝트 세팅 및 기본 지도 화면, T2 장소 선택·저장
- **팀원 B:** T3 위치 정보 조회, T4 거리·이동 시간 계산
- **팀원 C:** T5 방문 순서 추천 로직 및 단위 테스트
- **팀원 D:** T6 경로 지도 표시, T7 예상 이동 시간·거리 표시

**진행 순서:** 먼저 기본 지도와 장소 선택 기능을 구현하고 위치 정보를 가져온다. 이후 장소 간 거리와 이동 시간을 계산한 뒤 이를 이용해 방문 순서를 추천한다. 마지막으로 추천 결과를 지도에 표시하고 전체 이동 시간과 거리를 제공한 뒤 통합 테스트를 진행한다.
