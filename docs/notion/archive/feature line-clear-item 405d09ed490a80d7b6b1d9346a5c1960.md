## 무엇을 했나

아이템 모드의 필수 아이템인 줄 삭제(L)를 구현했다.
블록의 무작위 한 칸에 L이 붙고, 블록이 고정되면 L이 있는 줄을 꽉 차지 않아도 삭제한다.

## 정한 규칙

- L로 지운 줄도 누적 줄 수에 포함 (속도 증가·다음 아이템 지급에 반영)
- L 줄과 완성 줄이 같이 생기면 한 번에 삭제하고, 점수는 동시 삭제 규칙대로 계산
(예: L 1줄 + 완성 1줄 = 2줄 동시 삭제 2,500점)
- 삭제 연출은 일반 줄 삭제와 동일 (0.3초 흰색)
- 아이템 지급 시 E(작은 폭탄)와 L 중 무작위

## 구조 변경 (팀원 참고)

- `GameItem`에 `rowsToClear()` 기본 메서드 추가
→ "보드를 직접 바꾸는 아이템"(폭탄)과 "엔진에 줄 삭제를 요청하는 아이템"(L)을 모두 지원
→ 기존 아이템은 수정할 필요 없음
- 새 아이템 추가 방법: `GameItem` 구현 → `GameEngine` 생성자의 기본 아이템 목록에 추가
- `SmallBombTest`의 엔진 생성 도우미에 폭탄만 지급하도록 assigner를 주입함
