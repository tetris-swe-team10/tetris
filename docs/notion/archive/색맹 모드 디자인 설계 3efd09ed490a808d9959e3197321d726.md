상태: 완료

### **색상 없이도 인식 가능한 기호/패턴을 사용**

| 블록 | 색맹 모드 색상 | 패턴 |
| --- | --- | --- |
| I | `#56B4E9` | 가로선 |
| O | `#F0E442` | 점 |
| T | `#CC79A7` | 격자 |
| S | `#009E73` | 오른쪽 사선 `/` |
| Z | `#D55E00` | 왼쪽 사선 `\` |
| J | `#0072B2` | 세로선 |
| L | `#E69F00` | 교차 사선 |
- **S/Z:** `/`와 `\`
- **J/L:** 세로선과 교차선
- **J/T:** 파랑과 분홍, 세로선과 격자

### 표현 기준

- 패턴 간격은 셀 폭의 약 `20~25%`
- 패턴 선은 `1.5~2px`
- 밝은 블록에는 어두운 패턴, 어두운 블록에는 밝은 패턴
- 모든 블록에 어두운 외곽선 적용
- 패턴은 블록이 회전해도 방향이 바뀌지 않도록 고정
- 고정된 블록에도 같은 패턴 유지
- 유령 블록은 채우지 않고 패턴이 들어간 점선 외곽선으로 표시
