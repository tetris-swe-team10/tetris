반면 **기본 보드·이동·회전·낙하·점수·NEXT·기록 저장·난이도별 생성 확률**은 구현과 테스트 근거를 확인했어. 최신 `main` 사본에서 **153개 테스트 통과, 전체 Line Coverage 70.00%**였어. 폭탄 깜빡임 PR #37의 **160개·70.65%는 아직 미병합 브랜치 결과**야.

추가로 두 가지는 해석 확인이 필요해.

- **4-1:** 현재는 전체화면·창·세로 모드인데, 평가 기준은 ‘미리 정의된 크기 3개’야. 세로 폭 640 설정과 최소 폭 800도 충돌해.
- **6-1:** 체크리스트는 Java 11, 우리 프로젝트와 모범 예시는 Java 21이야. 올해 명세를 기준으로 확인해야 해.
