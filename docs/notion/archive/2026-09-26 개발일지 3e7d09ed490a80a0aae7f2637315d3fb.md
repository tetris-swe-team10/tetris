#### 2. 스코어보드 기능 보강 (`feature/game-over`)

종료 화면에 필요한 기능 추가. **기존 메서드는 수정하지 않고 추가만 했습니다.**

- `isHighScore()` — 순위 진입 판정 (이름 입력창 표시 결정)
- `saveAndGetRank()` — 저장 후 순위 반환 (강조 표시용)
- `clear()` — 설정의 기록 초기화용
- 상위 10개만 유지 + 테스트 13개

임의로 정한 것: 동점 시 기존 기록 유지, 0점은 등록 제외

#### 3. 게임 종료 화면 구현 (`feature/game-over`)

`GameOverView` 신규 + `App.java`에 화면 전환 추가.

```
게임오버 → 결과 화면 → (순위 진입 시) 이름 입력 → 순위표 + 강조
```

**시안과 달라진 점:** 이름 입력을 별도 화면 대신 단계 전환 방식으로 구현했습니다. 공간 문제로 FINAL SCORE 박스 자리에 순위표가 들어갑니다. "플레이 횟수"는 현재 데이터로 산출 불가해 제외했습니다.

#### 2. 점수 계산 로직 담당자

`GameView.setScore()`를 부르는 코드가 없어 종료 화면 점수가 계속 0으로 나옵니다.

#### 3. `Board`에 블럭 종류 저장

`lock()`에서 `cells[r][c] = 1`로 저장해 블럭 종류가 사라집니다. 그래서 쌓인 블럭이 전부 한 색으로 표시돼요. 요구사항의 "각 블럭이 모두 다른 색상"을 위해 어차피 필요해 보입니다.

`cells`를 `TetrominoType[][]`으로 바꾸고 `getCell()`은 0/1을 그대로 반환하게 하면 기존 코드가 안 깨집니다. 핵심 파일이라 임의로 안 건드렸습니다.

#### 4. 색맹 모드 방식 (디자인)

시안은 색을 다 빼고 흰색+문자로만 표시하는데, 요구사항은 "색맹도 구분이 쉽도록 **바꿔주는**" 기능이라 색맹 친화 색상으로 **교체**하는 쪽으로 보입니다. 색각이상자도 색을 보는 사람이라서 이렇게 하는게 좋대여

→ **색맹 친화 팔레트 + 문자 표시** 둘 다 적용을 제안합니다.

그리고 일반 모드 색도 조정이 필요해 보여요. S(초록)/Z(분홍)은 적록색맹에서, J(파랑)/T(보라)는 청황색맹에서 구분이 어렵습니다. 요구사항에 "좌우가 바뀐 블럭은 대비되는 색상"이 명시돼 있습니다.

>>이건 동의하시면 이대로 제가 화요일까지 구현해가겠습니다!!!
