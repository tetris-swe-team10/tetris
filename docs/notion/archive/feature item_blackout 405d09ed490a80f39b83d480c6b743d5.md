카테고리: 기능

## 암전 `B`

- **발동:** B 블록 고정 후 다음 블록이 생성될 때
- **표현:** 보드 전체를 어둡게 하고, 현재 조작 블록의 중심을 따라 **지름 약 4칸인 원형 영역만 밝게 표시**
- **시야:** 원 안의 쌓인 블록은 보이고, 원 밖은 어둡게 가림
- **유지:** 원형 시야가 블록의 이동·낙하를 따라감
- **종료:** 해당 블록이 고정되면 즉시 정상 시야로 복구. **3초 제한은 제거**
- **유지되는 정보:** NEXT·점수·보드 외곽선은 정상 표시하고 충돌·줄 삭제 규칙도 유지
