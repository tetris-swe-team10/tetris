# 무게추(W) 아이템

- 담당: 정수연
- 작업 브랜치: `feature/weight-item` (최신 `main`에서 분기)
- 작업 이슈: #(이슈 번호) / 작업 PR: #(PR 번호)
- 출처: 2차 명세 무게추 아이템 항목, 팀 확정 규칙 W-1~W-9

## 사용자 시나리오

아이템 모드에서 누적 10줄을 삭제하면 새로 보충되는 NEXT가 등록 아이템(E/B/K/L/W) 중 하나로 결정된다.
W가 뽑히면 NEXT 블록이 너비 4칸 무게추로 **교체**되고, 모든 칸에 `W`가 표시된다.
사용자는 닿기 전까지 좌우로 위치를 정한다. 처음 바닥이나 블록에 닿는 순간 좌우가 잠기고,
무게추가 낙하 틱마다 한 칸씩 내려가며 겹치는 칸만 지운다. 바닥에 도달하면 무게추는 사라지고 다음 블록이 나온다.

## 기능 명세와 경계 조건

| 항목 | 규칙 |
| --- | --- |
| 모양·문자 | 너비 4칸 `.WW.` / `WWWW`, 모든 칸에 `W` 표시. NEXT 아래 "W 무게추 · 닿으면 아래 4열을 뚫고 내려가며 삭제" |
| 등장 | 아이템 모드 누적 10·20·30…줄 경계 통과 시 새 NEXT 지급. 등록 아이템 전체(E/B/K/L/W) 중 균등 무작위. 벌칙 예약·진행 중에는 E/L/W 중 균등 |
| 지급 방식 | 부착형(E/B/K/L)은 블록의 한 칸에 부착, 블록형(W)은 새 NEXT를 같은 생성 위치의 무게추로 교체. 이미 보인 NEXT는 바꾸지 않음 |
| 회전 | 불가. 회전 키·명령 무시 |
| 닿기 전 | 좌우 이동 가능, 자동·아래 키 낙하 점수는 일반 블록과 동일 |
| 접촉 | 처음 바닥·블록에 닿는 순간 좌우 이동 잠김. 이 순간에는 아직 파괴하지 않음 |
| 파괴 | 이후 낙하 틱마다 1칸씩 내려가며 무게추와 겹치는 칸(4열 범위)만 삭제. 범위 밖 열 유지, 위 블록을 떨어뜨리거나 줄을 압축하지 않음 |
| 바닥 도달 | 무게추 아랫줄이 마지막 행에 도달하면 즉시 사라짐(보드에 고정되지 않음) → 다음 블록 생성 |
| 파괴 중 입력 | 아래 키·하드 드롭 시 남은 파괴를 즉시 바닥까지 진행. 하드 드롭은 닿기 전에 눌러도 접촉 후 바닥까지 한 번에 진행 |
| 점수·줄 수 | 파괴 구간과 지운 칸은 점수·누적 줄 수·속도 증가·아이템 지급에 포함하지 않음 |
| 암전(B) 상호작용 | 무게추가 암전 대상이면 처음 닿는 순간 암전 종료(일반 블록의 착지와 동일 시점) |
| 생성·게임 오버 | 일반 블록과 같은 위치(0행 3열)에 생성. 생성 자리가 막히면 일반 블록처럼 게임 오버 |
| 일시정지 | 이동·자동 낙하·파괴 모두 정지, 재개 시 이어서 진행 |
| 일반 모드 | 지급되지 않음 |
| 데모 | 데모 모드에서 숫자 `4`로 다음 NEXT에 무게추 예약 |

## 구현 구조

- `PieceItem extends GameItem`: 블록 자체가 아이템인 경우의 계약. `createPiece(row, col)`로 전용 블록을 만든다.
- `WeightItem`: 문자 `W`, 설명, `createPiece()`가 `WeightPiece` 반환. 보드에 고정되지 않으므로 `onLock`·`rowsToClear`는 호출되지 않는다.
- `WeightPiece extends Tetromino`: `type == null`(RWS 생성기·팔레트 테스트 영향 없음), 고정 모양 복사본 반환, `canRotate() = false`, 접촉 상태 `anchored`.
- `Tetromino.canRotate()`: 기본 `true`. `GameEngine.rotateClockwise()`가 확인한다.
- `ItemAssigner.award(piece, penalties)`: 엔진 지급 진입점. 기본 구현은 `attachTo` 후 같은 블록 반환(기존 람다 assigner 호환).
- `RandomItemAssigner.award()`: 전체 후보 균등 선택 → 블록형이면 교체, 부착형이면 무작위 칸에 부착. 기존 `attachTo()`는 부착형만 후보로 사용한다.
- `GameEngine`: 무게추면 `moveDown()`이 닿기 전 낙하/접촉(`fallWeight`)과 파괴(`drillOneRow`)를 분기. `tick()`은 파괴 중 1칸, 아래 키는 바닥까지. 바닥 도달 시 기존 `resolveLockedBoard()`로 다음 블록 생성.
- `PieceSnapshot.isItemPiece()`: `type == null && item != null`. `GameView`는 블록형 아이템의 모든 칸에 문자를 그린다.

## 검증

```powershell
.\gradlew.bat :app:test
.\gradlew.bat :app:test :app:uiTest :app:jacocoTestReport
.\gradlew.bat :app:run
```

`WeightItemTest`(12개):
- 고정 모양·복사본 반환, 문자·설명, 5종 문자 중복 없음, 회전 불가(엔진·명령 경로)
- 닿기 전 좌우 이동·벽 경계(0~6열)·낙하 점수
- 빈 보드에서 바닥 도달 즉시 사라짐, 보드에 남지 않음
- 접촉 시 좌우 잠김, 틱당 1칸 파괴, 범위 밖 열·떠 있는 칸 유지, 무득점·줄 수/속도 불변
- 파괴 중 아래 키·하드 드롭·명령 경로로 바닥까지, 위에서 하드 드롭 시 낙하 점수만 득점
- 일시정지 중 이동·파괴 정지 후 재개
- 암전 대상 무게추가 닿으면 암전 종료
- 데모 단축키, 생성 자리 막힘 시 게임 오버
- 10줄 경계에서 새 NEXT만 교체, 승격 후 동일 블록
- 부착/교체 선택, 부착 전용 경로의 W 제외, 기존 람다 assigner 호환
- 5종 균등 분포, 벌칙 중 E/L/W 유지

`WeightItemViewTest`(uiTest): NEXT 설명, 데모 안내·숫자 4, 회전 키 무시, 좌우 이동, 하드 드롭 후 사라짐.

수동 확인: 설정 → 데모 모드 ON(간격 1줄) → 아이템 모드 시작 → `4` 입력 후 한 블록 내려 NEXT에 W 확인 → 좌우 이동·회전 키 → 쌓인 블록 위에서 닿는 순간 좌우 잠김 → 틱마다 4열만 지워지며 내려가는지 → 바닥에서 사라지는지 → 점수·LINES 불변 확인.
