# 회전 잠금 K

아이템 모드의 공통 지급 목록에 K를 추가한다. 기본 10줄마다 새 NEXT에 선택 가능한 E/B/K를 균등 추첨하며 데모 지급 간격도 그대로 적용한다.

| 항목 | 규칙 |
| --- | --- |
| 발동 | NEXT의 K 블록이 현재 블록으로 승격되는 순간. 이전 블록의 회전은 제한하지 않는다. |
| 표현 | 실제 점유 칸의 K 배지와 `K 회전 잠금 · 현재 블록` 안내 |
| 시야 | 보드·현재 블록·NEXT 모두 정상 표시 |
| 유지 | K 블록 자체가 기본 생성 방향을 유지하며 모든 게임 회전 명령을 거부한다. 일시정지도 해제하지 않는다. |
| 종료 | K 블록 고정 즉시 해제. 줄 삭제 연출과 다음 블록에 잠금이 남지 않는다. 시간 제한 없음. |
| 유지되는 기능 | 좌우 이동, 소프트·하드 드롭, 충돌, 줄 삭제, 점수, 메뉴 입력 |

NEXT 설명: `K 회전 잠금 · 이 블록은 회전 불가`.

GameItem.onAssigned에서 종류를 예약하고 onSpawn에서 K를 활성화한다. GameEngine의 공통 회전 함수가 활성 상태를 검사하므로 입력 경로와 관계없이 차단된다. 고정 시 finishActive가 상태를 해제한다. B는 기존대로 고정 후 다음 블록에 발동한다. 두 벌칙의 예약·대기·활성 중에는 B/K 모두 새 추첨에서 제외하며, 10줄 지급은 다른 후보로 유지한다. 게임 오버와 새 게임에서는 효과가 남지 않는다.

검증: NEXT 예고와 이전 블록 회전, 생성 방향 보존, 엔진·명령 경로 회전 차단, 정상 이동·드롭, 일시정지, 소프트/자동/하드 고정 종료, 줄 삭제·게임 오버, B/K 상호 배제 및 기존 암전 회귀.
