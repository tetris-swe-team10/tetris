## 연동 경계

C는 `ConnectionChannel`을 사용해 게임 중 스냅샷·공격·종료를 송수신한다.
콜백은 메시지 순서대로 하나씩 전달한다. `start`가 반환되기 전에 C가 게임 수신 핸들러를 설치한다.
A 화면도 공용 렌더러를 주입받으므로 기존 `BoardRenderer` 시그니처를 유지한다.
랙/끊김 기준은 팀 결정 필요 항목이며, 자동화 결과를 실제 LAN 200ms 측정 결과로 쓰지 않는다.
