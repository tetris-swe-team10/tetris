# 암전 B 구현 계획 및 현재 상태

## 지급 계약

2차 요구사항 7쪽에 따라 아이템 모드의 누적 10·20·30줄 경계마다 지급을 예약한다. 초과 줄 수를 보존하고, 이미 표시된 NEXT는 변경하지 않는다. 새로 보충되는 NEXT에 공통 ItemAssigner가 아이템을 부착한다.

한 번의 삭제로 여러 경계를 넘으면 경계 수만큼 지급 횟수를 누적하고, 이후 새 NEXT마다 하나씩 소비한다. 종류 추첨과 B 예약은 실제 NEXT를 만드는 시점에 수행한다.

현재 기본 등록 목록은 작은 폭탄 E, 암전 B, [회전 잠금 K](rotation-lock.md), [줄 삭제 L](line-clear-item.md)다. 선택 가능한 등록 아이템을 균등 추첨한다. 별도 3% 벌칙 추첨이나 E 우선 지급은 없다. 일반 모드에서는 지급하지 않는다.

B 또는 K가 예약·대기·진행 중이면 B와 K를 모두 후보에서 제외한다. 10줄 지급은 유지하며 나머지 E/L 후보를 추첨한다. 사용자 정의 등록 목록에 선택 가능한 후보가 하나도 없으면 구성 오류를 발생시킨다. 추후 아이템 추가 시 항상 선택 가능한 후보를 유지해야 한다.

## 암전 효과

- 기존 테트로미노의 무작위 점유 칸에 B를 부착한다. 이동·회전·회전 취소와 NEXT 승격은 공통 ItemAttachment를 사용한다.
- NEXT 안내: `B 암전 · 고정 후 다음 블록 착지까지 원형 시야`.
- B 고정 시 효과를 대기 상태로 만들고, 줄 삭제 연출 완료 후 다음 블록이 정상 생성되면 원형 시야를 적용한다. 해당 블록이 고정되는 즉시 종료하며, 시간 제한은 없다.
- 일시정지 중에도 대상 블록과 효과 상태를 유지한다. 대상 블록의 고정으로 줄 삭제 연출이 시작되면 이미 정상 시야로 돌아온다.
- 보드를 어둡게 그리고 현재 블록의 실제 점유 영역 경계 상자의 중심을 따라 지름 4칸의 원형 시야를 이동시킨다. 원 안의 쌓인 블록은 보이고 원 밖은 숨긴다. 이동·회전·낙하 시 중심을 다시 계산한다. 충돌·줄 삭제·점수 계산에는 원래 보드를 사용한다.
- 고정된 칸의 아이템 배지는 남기지 않는다. 삭제 대상 행을 알려주는 기존 줄 삭제 연출은 암전 중에도 표시한다.
- 현재 블록·NEXT·보드 경계·점수는 표시한다. 현재 블록은 원 밖으로 나와도 전체를 표시한다. 현재 고스트 기능은 없으며 도입 시 암전 중 숨겨야 한다.
- 다음 블록 1개의 수명으로 효과를 관리한다. 종료 시 최신 보드를 표시하고 기존 NEXT는 바꾸지 않는다.
- 게임 오버와 재시작은 효과 상태를 초기화한다.

## 구조와 구현 순서

1. **공통 지급 연결 완료:** 독립 PenaltySpawner 제거. RandomItemAssigner의 E/B/K/L 목록과 선택 가능 여부 계약 사용.
2. **상태 연결 완료:** GameItem의 onAssigned에서 예약, onLock에서 대기. PenaltyController가 예약·대기·활성·종료를 관리한다. 기존 E의 3인자 onLock은 그대로 호출한다.
3. **화면 연결 완료:** 공통 ItemMarker로 배지와 설명 표시. GameSnapshot의 활성 상태와 현재 블록 위치로 원형 클리핑을 적용하고 현재 블록은 클리핑 밖에서 그린다.
4. **자동 검증 완료:** 10줄 지급을 거쳐 B 예고·발동, 3초가 지나도 지속, 대상 블록 고정 시 종료, 일시정지·삭제 연출, 중첩 방지, 공통 선택 분포, 실제 화면 픽셀을 확인한다. 폭탄 회귀 테스트는 E 할당기를 주입하여 종류 추첨과 분리한다.
5. **팀 통합 시 후속 작업:** 다른 아이템을 공통 목록에 등록하고 문자 중복·선택 비율·효과 상호작용을 확인한다. 무게추의 특수 형태와 낙하 중 효과는 별도 생명주기 확장이 필요하다. 조작 반전은 미구현이며 회전 잠금은 별도 명세를 따른다.

실행: `bash gradlew test uiTest --no-configuration-cache`.

## 빠른 데모 확인

설정에서 데모 모드를 켜고 데모 아이템 지급 간격을 −/+ 버튼으로 1~100줄 중 선택한다. 기본값은 1줄이다. 아이템 모드에서 지정한 줄 수를 삭제하면 새 NEXT에 공통 목록의 아이템이 등장한다. B만 강제 선택하지는 않는다. 게임 중 간격 변경은 설정에서 복귀할 때 적용되며, 변경 후 삭제 줄부터 새로 계산한다. 기존 NEXT와 이미 예약된 지급은 유지한다. 데모를 끄면 10줄 간격으로 돌아간다. 설정값은 앱 실행 중 유지하며, 설정 저장을 누르면 다음 실행에도 복원한다. 저장·초기화 규칙은 [설정 명세](settings.md)를 따른다.
