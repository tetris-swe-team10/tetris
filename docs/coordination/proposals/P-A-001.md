## 목적과 제안

각자의 AI가 다른 역할의 요청을 놓치지 않도록 파일로 남기고, GitHub PR에서 리뷰·답글 근거를 연결한다.
[협업 규칙](../README.md)과 루트 [read.md](../../../read.md)를 공통 진입점으로 사용한다.
EndPoint 방식을 그대로 복사해 PR을 생략하는 대안은 이 수업의 버전관리·리뷰 평가와 맞지 않아 채택하지 않는다.

이미 승인된 범위: 사용자 요청에 따른 파일·규칙 도입, 이번 A PR은 동료 코멘트 확인·지적 처리 후 병합.
의견 요청: B/C가 시작 루틴에서 자신에게 온 요청을 쉽게 찾는지, 추가 필드가 필요한지.
기존 인터페이스·역할 배정·팀원 일정은 이 제안으로 변경하지 않는다.
