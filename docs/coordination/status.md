# 팀 작업 현황과 인수인계

> 갱신일: 2026-11-09 · 기준: 로컬 `3ccc9ac`와 첨부 Notion 사본 · 최신 원격 전체 동기화/기능 재실행은 이번 작업에서 확인하지 않음

## 노션에서 확인되는 기여 분야

| 사람 | 노션·기존 문서에 남은 분야 | 담당 근거를 읽을 때 주의 |
| --- | --- | --- |
| 박서현 | 요구사항·운영 방식, 시작 메뉴, 설정, 색맹 디자인, B/K, 아이템 명세 | 문서 생성자와 전체 구현 전담자는 같다고 단정하지 않음 |
| 정수연 | 개발환경 수정, 종료·기록, 색맹 구현·통합, L, 기존 W 명세 | 이후 공통 코드 수정은 커밋·PR와 함께 확인 |
| 정혜원 | 초기 환경, 기본 게임·조작, 점수·난이도·확률, E·고스트, 점검·배포 | AI 도움을 포함한 실제 변경 근거를 이슈·PR로 연결 |

이 표는 과거 기록의 색인이다. 새 작업의 assignee·일정·소유권을 정한 배정표가 아니다. 공동 코드 변경은 관련 팀원과 연동 규칙을 기록한다.

## 이번 정리에서 확인한 상태

- 일반/아이템 모드·난이도·점수·기록·설정·E/B/K/L/W·고스트·폰트·배포 관련 코드/명세가 로컬에 존재한다. [코드 지도](../project-overview.md)를 따른다.
- 이번 작업의 범위는 AI 지침과 문서 정리다. 게임 테스트·커버리지 수치를 새로 측정하지 않았다.
- 원문 29개와 이미지·CSV 총 38개 파일을 [Notion 자료](../notion/README.md)에 보존했다. 각 원문의 완료/미완료 상태는 과거 메타데이터다.
- `feature/windows-package`의 패키징 커밋이 문서 작업의 로컬 기준에 포함돼 있다. 이 문서만으로 PR #54의 최신 병합/배포 상태를 단정하지 않는다.
- 기존 `app/bin`의 로컬 변경·산출물은 이번 문서 작업에 포함하지 않는다.

## 다음 확인 순서

1. [열린 질문](questions.md)에 적힌 원문·e-class 해석과 평가 증거를 확인한다.
2. 최신 GitHub 이슈·PR에서 해결된 과거 점검 항목을 찾아 중복 작업을 줄인다.
3. 제출용으로 필요한 시점에만 같은 커밋에서 전체 커버리지를 새로 측정하고 보고서를 연결한다.
4. 스프린트별 실제 스토리 담당, 완료 조건, PR·리뷰·이월 사유를 기록한다. 과거에 없던 스프린트·승인·리뷰를 만들어 넣지 않는다.
