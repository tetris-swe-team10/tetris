# 줄 삭제(L) 아이템

- 담당: 정수연
- 작업 브랜치: `feature/line-clear-item` (최신 `main`에서 분기)
- 작업 PR: [#39 줄 삭제(L) 아이템](https://github.com/tetris-swe-team10/tetris/pull/39)
- 출처: 2차 명세 7·8·10쪽

## 사용자 시나리오

아이템 모드에서 누적 10줄을 삭제하면 새로 보충되는 NEXT에 공통 목록(E/B/K/L)의 아이템이 예고된다.
벌칙이 예약·진행 중이면 B/K를 제외한 E/L 중에서 선택하며, 데모 지급 간격도 유지한다.
L이 붙은 블록을 고정하면, L이 놓인 줄은 꽉 차 있지 않아도 일반 줄 삭제와 같은 방식으로 삭제된다.

## 기능 명세와 경계 조건

| 항목 | 규칙 |
| --- | --- |
| 형태·문자 | 일반 테트로미노의 실제 점유 칸 중 무작위 한 칸에 `L` 부착 (예: I 블록은 LOOO/OLOO/OOLO/OOOL) |
| 등장 | 아이템 모드 누적 10·20·30…줄 경계 통과 시 새 NEXT에 지급. 등록 아이템 중 균등 무작위 선택 |
| 이동·회전 | 블록과 함께 이동·회전. 최종 고정 위치의 L 행이 대상 |
| 발동 | 하강 실패로 블록이 고정된 직후 1회. 자동·소프트·하드 드롭 모두 동일 |
| 삭제 범위 | L이 놓인 행 전체. 행이 꽉 차 있지 않아도 삭제 |
| 완성 행과 동시 발생 | L 행과 완성 행의 합집합을 한 번에 삭제. 겹치는 행은 1번만 셈 |
| 연출 | 일반 줄 삭제와 동일한 0.3초 흰색 강조 후 삭제·압축. 일시정지 시 연출 시간도 정지 |
| 점수 | 기존 줄 삭제 규칙과 동일. 합집합 줄 수 n에 대해 `1000·n + 500·(n-1)` (1/2/3/4줄 = 1000/2500/4000/5500) |
| 누적 줄 수 | L로 삭제한 줄도 누적 삭제 줄에 포함 → 5줄마다 속도 증가, 10줄마다 아이템 지급에 반영 |
| 일반 모드 | 아이템이 지급되지 않으며, 주입되더라도 효과를 실행하지 않음 |
| 식별 | NEXT와 현재 칸에 `L` 배지. NEXT 아래 "L 줄 삭제 · 고정 시 L이 있는 줄을 삭제" 표시. 색맹 모드에서도 문자 유지 |
| L자 블록과 구분 | 아이템 설명 문구에 항상 "줄 삭제"를 붙여 L자 테트로미노와 구분 |

## 구현 구조

- `GameItem.rowsToClear()` (기본 메서드 추가): 아이템이 엔진에 삭제를 요청할 행을 반환. 기본값은 빈 집합이므로 기존 아이템(작은 폭탄)은 변경 없음.
- `LineClearItem`: `onLock`에서는 보드를 바꾸지 않고, `rowsToClear`에서 자기 행만 반환.
- `GameEngine.resolveLanding()`: 고정 → `onLock` → `rowsToClear` → `findFullRows()`와 합집합 → 기존 CLEARING 절차.
- 새 아이템도 `GameItem`을 구현하고 엔진 기본 등록 목록에 추가하면 동일한 절차로 동작한다.

## 검증

```powershell
.\gradlew.bat :app:test
.\gradlew.bat :app:test :app:uiTest :app:jacocoTestReport
.\gradlew.bat :app:run
```

`LineClearItemTest` 주요 검증:
- 문자·설명, 다른 아이템과 문자 중복 없음
- 자기 행만 요청, 보드 직접 변경 없음, 보드 밖 좌표 거부
- 미완성 행 삭제·연출·점수·위 칸 압축
- L 행 + 완성 행 동시 삭제(합집합·콤보 점수), 이미 꽉 찬 행은 1번만 계산
- 일반 모드 무시, 회전·하드 드롭 후 최종 위치 기준 삭제
- L 행이 누적 줄·속도·다음 아이템 지급에 반영
- I 블록 4칸 모두에 부착 가능, NEXT 표시 정보

수동 확인: 게임 시작 → 아이템 모드 → 누적 10줄 삭제 → NEXT에 L 표시 확인 → 미완성 줄에 고정 → 해당 줄 삭제 및 점수 증가 확인.

통합 시 벌칙 상태를 받는 `onLock` 콜백과 폭탄 `ITEM_EFFECT` 연출을 보존했다.
`rowsToClear`는 즉시 효과와 연출이 있는 효과 모두 실제 효과 실행 뒤 수집하여 완성 행과 합친다.
