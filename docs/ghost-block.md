# 고스트 블록과 낙하 범위 안내선

- 작업 브랜치: `feature/ghost-block`
- 현재 블록과 같은 회전 모양의 착지 위치를 옅은 채움과 밝은 테두리로 표시한다.
- 현재 블록의 가장 왼쪽·오른쪽 점유 열에서 착지 위치까지 세로 점선을 그린다. 각 끝 열의 실제 점유 칸 아래부터 고스트 위까지 연결하며, 고정 블록 뒤에 그려 쌓인 블록을 가리지 않는다.
- 이동·회전·낙하 시 읽기 전용 스냅샷을 기준으로 다시 계산한다. 색맹 모드에서도 명도와 윤곽으로 구분한다.
- 착지 위치와 현재 위치가 같으면 겹치는 고스트·안내선을 생략한다. B 암전, 줄 삭제, 폭탄 연출, 게임 종료 중에도 생략한다. 정상 조작 중 일시정지는 현재 미리보기를 유지한다.
- 착지 예측은 블록·보드·점수·아이템 효과를 변경하지 않으며, 아이템 효과 적용 전 블록 자체가 고정될 위치를 보여준다.

검증: 모든 도형·회전의 실제 하드 드롭과 예측 일치, 요철·가려진 구멍·벽 충돌, 일시정지와 아이템 연출, 실제 JavaFX 렌더링 및 반응형 화면을 확인한다.
