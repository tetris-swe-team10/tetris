# 설정 저장·초기화·키 변경

시작 메뉴 설정과 게임 중 ESC 설정에서 같은 기능을 사용한다. 하단 복귀 버튼과 같은 줄 오른쪽에 **설정 저장**, **설정 초기화** 버튼을 배치한다.

## 저장과 재실행

- 화면 모드·조작 키는 변경 즉시 적용한다. 기본 낙하 속도와 데모 ON/OFF·지급 간격의 게임 중 변경은 설정에서 복귀할 때 반영한다.
- **설정 저장** 버튼으로 위 항목과 색맹 모드를 함께 파일에 저장한다. 성공·실패를 화면에 표시한다.
- 색맹 모드는 기존의 변경 즉시 자동 저장도 유지한다.
- 저장 위치는 사용자 홈의 `.team10-tetris/settings.properties`다. 저장된 화면 모드는 다음 앱 시작 때 실제 창에 적용한다.
- 이전 색맹 설정만 있는 파일도 읽는다. 잘못된 값은 기본값으로 복원하고, 중복·충돌이 있는 조작 키는 네 키 모두 기본 배치로 복구한다.
- 임시 파일에 쓴 뒤 교체해 저장하며, 알 수 없는 기존 설정 키는 유지한다.

## 기본 낙하 속도와 난이도

설정은 기본 낙하 간격(느리게 1250ms / 보통 1000ms / 빠르게 750ms)을 정한다. 모든 난이도에서 선택한 기본 간격으로 시작한다. 이후 누적 5줄마다 Easy 80ms, Normal 100ms, Hard 120ms씩 간격을 줄인다. 가속은 시간이나 확률이 아닌 삭제 줄 수에 따른다.

`실제 간격 = max(200ms, 기본 간격 - 가속 단계 × 난이도별 감소량)`

Normal에서 5줄 삭제 후 간격은 느리게 1150ms / 보통 900ms / 빠르게 650ms다. 설정을 바꿔도 누적 가속 단계는 유지하며, 최소 200ms에 도달하기 전까지 기본 속도 차이가 남는다. Controller는 모델이 계산한 실제 간격을 그대로 사용한다. 스냅샷과 기존 낙하 점수 규칙도 이 간격을 사용하므로 실제 간격이 1000ms 미만이면 기존 규칙에 따라 성공한 낙하당 200점, 그 외에는 100점이다. 줄 삭제와 아이템 연출 시간은 속도 설정으로 바뀌지 않는다.

## 기본값 복원

**설정 초기화**는 창 모드, 보통 낙하 속도, 색맹 OFF, 데모 OFF, 데모 지급 간격 1줄, 기본 방향키 배치로 복원하고 저장한다. 점수 기록은 변경하지 않는다. 화면의 선택 상태와 조작 키 안내도 갱신한다. 저장에 실패하면 기존 설정을 유지한다.

## 키 변경

1. **키 변경**을 누른다.
2. 왼쪽 이동 / 오른쪽 이동 / 회전 / 내리기 중 변경할 조작을 클릭하거나 Tab으로 이동해 Enter로 선택한다.
3. 사용할 키 하나를 누른다. 네 조작에는 서로 다른 키를 사용한다.
4. **적용**하면 현재 게임에서 바로 사용한다. **취소**하면 변경 전 배치를 유지한다.
5. 재실행 후에도 유지하려면 설정 화면에서 **설정 저장**을 누른다.

입력 대기 중 ESC는 해당 입력을 취소한다. ESC(설정), SPACE(하드 드롭), Enter/Tab(화면 조작), 숫자 1~3 및 숫자패드 1~3(데모), 보조 키와 조합 키는 지정할 수 없다. 게임 중에도 조합 키 입력은 무시한다. 설정 화면·메뉴 탐색은 기존 방향키를 유지한다. 회전 잠금 K는 사용자 지정 회전 키에도 적용된다.

## 검증

`bash gradlew test uiTest jacocoTestReport --no-configuration-cache`

- 전체 설정 저장 후 새 객체로 재실행 복원, 이전 파일 호환, 손상·누락·잘못된 값 복구
- 기본값 복원 후 재실행 및 점수 파일 보존, 파일 쓰기 실패 시 상태 유지
- 실제 키 변경 창의 중복/고정/조합 키 거부, 적용/취소, WASD 게임 조작과 SPACE 하드 드롭
- 저장·초기화 버튼 및 초기화 후 키보드 탐색, 게임 중 설정창의 동일 기능
- 저장된 화면 모드의 앱 시작 적용, 속도 설정의 실제 낙하와 300ms 줄 삭제 연출 분리

화면 확인용 키 변경 PNG는 `app/build/ui-smoke/key-bindings.png`에 생성한다. UI 검증은 JavaFX 데스크톱 환경이 필요하다. 커버리지는 main 코드를 제외하지 않고 test와 uiTest 데이터를 합산한다.
