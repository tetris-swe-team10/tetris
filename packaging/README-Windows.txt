실행 환경: Windows 11 x64

1. ZIP 파일 전체를 원하는 폴더에 압축 해제합니다.
2. Tetris 폴더 안의 Tetris.exe를 실행합니다.

Java를 따로 설치할 필요가 없습니다.
Tetris.exe 옆의 app, runtime 폴더를 함께 유지해 주세요.
EXE 파일만 다른 폴더로 옮기면 실행되지 않습니다.

기본 게임 조작
  좌우 방향키: 이동
  위쪽 방향키: 회전
  아래쪽 방향키: 내리기
  Space: 바로 내리기
  ESC: 설정/일시정지
